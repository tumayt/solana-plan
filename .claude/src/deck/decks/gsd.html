Context

Get Shit Done
(GSD)

A meta-prompting system for AI development

Normal prompting
You write every prompt yourself, one at a time, in a single session
Meta-prompting (workflows like GSD)
A system generates, sequences, and manages prompts for you. Each task gets a fresh session with structured context

What is GSD?

A meta-prompting system that structures AI development
into reliable, repeatable phases.

1
Init
Set up project
2
Discuss
Surface gray areas
3
Plan
Atomic task plans
4
Execute
Parallel fresh context
5
Verify
Auto-fix & confirm
Atomic git commits per completed task. Works with Claude Code, Codex, Cursor, Windsurf, etc.

Commands

Core Workflow

/gsd:new-projectQuestions, research, requirements, roadmap
/gsd:discuss-phaseCapture decisions before planning
/gsd:plan-phaseResearch + plan + verify for a phase
/gsd:execute-phaseRun plans in parallel waves
/gsd:verify-workUser acceptance testing
/gsd:shipCreate PR with auto-generated body
/gsd:nextAuto-advance to next workflow step
/gsd:fastInline trivial tasks, skip planning

Navigation & Quality

/gsd:progressWhere am I? What's next?
/gsd:map-codebaseAnalyze existing codebase
/gsd:reviewCross-AI peer review
/gsd:debugSystematic debugging with state
/gsd:workstreamsManage parallel workstreams
/gsd:pause-workCreate handoff for next session
/gsd:resume-workRestore from last session
/gsd:doRoute freeform text to right command
