Data Pipeline

How We Build Lending Data

  • Source of truth is on-chain. We read directly from blockchain events, not protocol APIs or third-party aggregators.
  • Two types of data to track:

Latest value

Supply/borrow caps, borrowable states. Just use the most recent event emitted.

Running totals

Deposits, withdrawals, borrows, repays. Sum them up from contract genesis.

Pipeline
Indexer → Raw Events → Protocol-Specific State → Unified Pool State → API
Bottleneck

Waiting for events to index from genesis is the slowest step when adding a new protocol.

Reusable work

Multiple protocols share ERC-4626 (a standard vault interface). Morpho, Euler, and Aave wrapped tokens all use it. Build once, reuse across protocols.

APY Calculation

Solved for All 5 Protocol Types

Aave V3 & Euler Lend

Full lending markets. They emit interest rates directly in their events. We read the rate and annualize it. Straightforward.

Morpho V1, V2 & Euler Earn

Supply-only vaults. Euler Earn is a direct clone of Morpho V1. Supply APYs are derived from the latest on-chain events. Borrow APYs are weighted from the underlying Morpho Blue market allocations. Each vault spreads deposits across multiple markets, so the effective borrow APY is a weighted average based on each market’s proportion of the vault.

All core fields mapped: supply, borrow, TVL, APYs, utilization, LTV, caps.

What’s Left to Figure Out

Reward APY
Protocols pay bonus tokens on top of base yield (e.g. MORPHO token rewards for Morpho vault depositors). We calculate base yield but not the bonus yet. Affects every protocol. Needs research into each reward distributor contract.
Vault depth
Morpho and Euler Earn vaults are wrappers around underlying lending markets. We can show vault-level supply APY now. To show weighted borrow APY and utilization, we need to track the underlying markets each vault deploys into.
Why vault depth matters

This is what customers are asking for. Giza wants to understand “how risk curators are actually deploying capital.” Sail frames risk at the curator level, not the protocol level. Vault-level data gets us live. But market depth is what they’re paying for.
