Interest rate model
06

Adaptive curve IRM

Morpho uses an adaptive curve IRM engineered to keep utilization close to a 90% target.

Self-correcting mechanism

When utilization exceeds 90%, the curve shifts upward. Higher rates slow new borrows and pull in fresh liquidity.

Downward adjustment

When utilization falls below target, the curve shifts down to encourage borrowing and put idle capital to work.

No governance input

The curve adapts autonomously. No admin needs to update parameters when market conditions shift.

Initial curve: rate at 0% utilization is 1/4 × r₉₀%
Adaptive shift: curve moves up when utilization stays above target
Key takeaways
07

What to remember

01

Isolated by design

Risk never bleeds across markets. Each pool is self-contained so a failure in one market never touches another. This is the core architectural promise.

02

Immutability is a tradeoff, not a feature

Markets can’t be patched after deployment. Oracle and IRM choice at creation time is permanent. Getting it right once matters more than flexibility.

03

Vaults are where risk actually lives

Passive depositors delegate that risk to the curator. The timelock is the main protection lever.

04

V2 changes the scope entirely

Adapters make Morpho general routing infrastructure, not just a lending protocol. Any yield source becomes reachable. The registry system is what keeps official vaults trustworthy.

05

Bad debt model matters

V1.0 socializes losses immediately. V1.1 defers them to the last withdrawers. This is a real differentiator when evaluating vault safety.

A2

Two mechanics worth understanding

Vault share exchange rate
How it works

Vault shares are not issued 1:1 with deposited assets. The exchange rate reflects the vault's total assets relative to total shares outstanding. As interest accrues in the underlying markets, total assets grow while share count stays fixed, so each share becomes worth more over time. A deposit of 10 USDC into a vault that has been accumulating interest since inception will receive fewer than 10 shares.

Interest accrual: two layers
Market level

AccrueInterest fires on every supply, borrow, or repay. The IRM recalculates the borrow rate first, then interest on outstanding borrows gets applied. feeShares = 0 means the protocol takes no cut at the market level.

Vault level

AccrueInterest on the vault updates totalAssets before any deposit math runs. This is where curator fees are collected, through minting new shares to the fee recipient rather than pulling assets out.

Deposit path vs borrow path
Vault deposit: User → Router → Vault → Morpho main contract
Collateral: User → Router → Morpho main contract
Borrow: Morpho main contract → User
