Figma MCP
Experiment Results

Cambrian Design · April 2026

How connecting Claude Code to Figma via MCP bridges design systems with AI-powered code generation — setup, workflow, and what we learned.

Context

What is Figma MCP?

  • MCP (Model Context Protocol) lets AI tools communicate directly with external services
  • Figma MCP connects Claude Code to your Figma files — read designs, write to canvas, generate code
  • Real-time bridge between your design system and your codebase
AI Tool
Claude Code
→
Protocol
MCP Server
→
Design
Figma
Features

Three core capabilities

Write on Canvas

Modify and create content directly in Figma. Currently free during beta — will become a usage-based paid feature.

Extract Context (Read)

Read design files, components, styles, and variables. Claude can analyze your entire design system from Figma.

Generate Code

Create code based on selected frames and components. Output adapts to your project’s stack and conventions.

Getting Started

Setup in 3 steps

1
Install Plugin
One command in Claude Code
claude plugin install figma@claude-plugins-official
2
Connect Figma
Share design file links with Claude. Grant screenshot permissions when prompted.
3
Upgrade Account
Dev or Full seat required for sufficient MCP API calls.
Caveat

Free tier MCP call limits are too low for real work. You need at least the Dev or Full seat at $20 USD/month to get enough calls.

Insight

Design system as AI context

  • Claude read the Figma design system and created reusable rules automatically
  • Prompts referencing the design system produced on-brand output consistently
  • After the session, Claude identified which files it would need for even better performance
  • Self-improving loop: each session teaches Claude more about our brand

The Iterative Loop

Each cycle makes the output more on-brand:

1 Read design system from Figma
↓
2 Generate rules & patterns
↓
3 Use rules in prompts
↓
4 Improve iteratively

Replicable Workflow

Any team member can connect to the Figma MCP, use this repo as a base, and get design-aware code generation immediately.

No manual style guide reading. No guessing colors or fonts. The AI reads the source of truth directly from Figma.
